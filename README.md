# Vumora — Watch Trending Videos & Shorts Online

Lightweight, modern video discovery web interface powered by the official **YouTube Iframe Player API**. Built by **Pawan Verma** / **PAWANGAMINGSTUDIO**.

---

## 🚀 How to Deploy on GitHub Pages (Drag & Drop)

1. Open your GitHub repository: `https://github.com/vumora/vumora.github.io` (or your personal GitHub repo).
2. Click **Add file** ➔ **Upload files**.
3. Drag and drop all the files from this directory into the root of your repo.
4. Commit your changes.
5. In GitHub repo settings: **Settings ➔ Pages ➔ Source: Deploy from a branch (`main` / root)**.
6. Your site is live!

## 🌟 Features Included

- **Official YouTube Iframe Embeds:** Standard YouTube Iframe Player mode (`youtube.com`), ensuring 100% video creator views and ad monetization.
- **Location-Aware Smart Feeds:** Automatically loads trending content tailored to user country and region.
- **Sticky Mini-Player Dock:** Video keeps playing seamlessly while scrolling feeds on both mobile and desktop.
- **Full-Screen 9:16 Shorts Reel:** Responsive vertical swipe experience for shorts.
- **Infinite Related Scroll:** Smooth waterfall recommendation algorithm.
- **28+ Global Languages Supported:** Seamless multilingual switching with complete RTL compatibility.
- **100% Compliant Amazon Affiliate Engine:** Contextually suggests relevant, high-converting product categories on Amazon.in (Tag: `vumora-21`) without fake ratings or misleading badges.
- **Viral WhatsApp Sharing:** Direct one-tap WhatsApp video sharing to boost traffic across India.
- **Progressive Web App (PWA):** Installable directly to home screens on Android and iOS.
- **SEO & Social Metadata:** Ready with XML Sitemaps, robots.txt, Open Graph, and Schema.org JSON-LD structured data.
